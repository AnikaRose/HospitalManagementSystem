# 🏥 Hospital Management System

A console-based **Hospital Management System** developed in **C**. The project uses file handling to store and manage hospital-related information.

## ✨ Features

* 👨‍💼 Admin Management
* 👨‍⚕️ Doctor Management
* 📅 Appointment Management
* 💰 Billing Management
* 🧪 Diagnostic Management
* 💾 File-based data storage

## 🛠️ Technologies

* C
* Code::Blocks
* GCC
* File Handling
* Structures
* Functions
* Header Files

## 📂 Project Structure

```text
Hospital-Management-System/
│
├── main.c
├── ai.h
├── head.h
│
├── admin.txt
├── appointment.txt
├── bill.txt
├── diagnostic.txt
├── doctor.txt
├── temp.txt
│
├── hms.cbp
└── README.md
```

The `.txt` files are used to store the application's data.

## ▶️ How to Run

### Using Code::Blocks

1. Open `hms.cbp` in Code::Blocks.
2. Build the project.
3. Run the program.

### Using GCC

```bash
gcc main.c -o hms
./hms
```
